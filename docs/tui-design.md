## 1. 背景与目标

Phase 1 交付了 tekl/tjek 工具链: 两条命令 `termux-extrakey-tekl` (编译写入) 与
`termux-extrakey-tjek` (JSON DSL 校验)。配键盘仍是"编辑文本文件 → 跑命令"的流程。

Phase 2 目标: 一个**可视化网格编辑器 TUI**, 所见即所得地编辑键盘布局, 作为
**tekl 的前端** 使用 — 不替代、不改写任何工具链逻辑。

- 直接操作"回报" 而非源码: 选中/增删按键、编辑组合键/标签/popup
- tekl 源码仍为最终产物与持久化格式 (构建于第一阶段工具链之上)
- 编译错误/警告直接在界面内联展示 (复用行列定位)
- 保存 = 写 tekl 源码 + 写 `~/.termux/termux.properties` (+ 可选 reload), 复用原子写与往返校验
- **tekl 工具链原样保留**: CLI (编译写入/`--watch` JIT) 与 tjek 校验器不动, TUI 仅消费
  它们的库接口 (parse/compile/updateProperties/reloadSettings)

**两条核心约束**:

1. **受限操作集**: 全部操作由方向键 + `ALT` + `SPACE` + `CTRL` + `ESC` + `ENTER`
   完成; 名称输入框是唯一的自由文本输入例外 (§6)。
2. **所见即所得是最高级要求**: 编辑结果即时反映在界面与真键盘上 —
   每个生效点自动写盘并 reload, 界面渲染与 Termux 实际显示规则一致 (§6.7)。

### 非目标 (此阶段)

- 不实现 tmux/多窗格终端、不引入额外运行时 (保持 Node 内置 + 现有依赖)
- 不保留 tekl 原始格式/注释 (保存为规范化输出, 见 §4.3)
- 不重写 JIT/`--watch` 行为 — 那是 tekl 的职责, TUI 不接管
- 不提供撤销 (CTRL 已承担选中/菜单职责, 见 §9)

## 2. 命令与定位

**tekl/tjek 命令保持原样**, 新增一个 TUI 入口 `termux-extrakey`
(package.json `bin` 追加一项; 入口 `src/cli.mjs`):

| 命令 | 行为 |
| --- | --- |
| `termux-extrakey` | 启动 TUI, 默认打开 `~/.termux/termux.tekl` (不存在则空白布局) |
| `termux-extrakey <file.tekl>` | 启动 TUI 并打开指定文件 |
| `termux-extrakey-tekl ...` (保留) | 编译写入 + `--watch` JIT, 与 Phase 1 完全一致 |
| `termux-extrakey-tjek ...` (保留) | JSON DSL 校验, 与 Phase 1 完全一致 |

- TUI 是纯前端: 加载走 `parser.mjs`, 保存走 `compiler-io.mjs` 的
  `updateProperties`/`reloadSettings`, 校验走 tjek 的 `validateExtraKeyJson` —
  不在 TUI 内复制任何编译/写入/校验逻辑。
- `--watch`/JIT 仍由 tekl CLI 提供; TUI 的实时校验是"编辑时预览",
  与 JIT 的"文件变更自动写入"是两个独立机制, 互不替代。

## 3. 界面布局

```
┌ termux-extrakey ──── keys.tekl ──────────────────────────────────────┐
│ 模式: ［键盘编辑］ 主键编辑 弹出键编辑            ←── 模式条           │
│                                                                       │
│  ←── 网格区 (所见即所得键盘矩阵) ──→                                  │
│  [ ESC ] [ TAB ] [ CTRL ] [ ALT ]                                     │
│  [ CTRL(C) ] [ ALT(A) ] [ HOME:Start ] [ ESC.F5 ]                     │
│  [ DRAWER ] [ KEYBOARD ] [ SCROLL ] [ SPACE ]                         │
│                                                                       │
│  ←── 覆盖面板 (菜单 / 预设值矩阵 / 名称输入框) ──→                    │
├─── 问题面板 (生效失败/警告) ──────────────────────────────────────────┤
│  ⚠ 第 2 行 6 键 / 第 1 行 4 键 — 行宽不一致                            │
├───────────────────────────────────────────────────────────────────────┤
│ ←→↑↓ 移动 · ALT 模式 · SPACE 选中/矩阵 · CTRL 菜单/选值 ·             │
│ ENTER 名称 · ESC 返回/退出                                            │
└───────────────────────────────────────────────────────────────────────┘
```

- **模式条**: M0/M1/M2 三个模式常显, 当前模式反白高亮 — ALT 循环始终可感知。
- **网格区**: 每行 = Termux 一行键盘, 单元格 = Termux 实际按键外观, 内容为该键的
  实际 tekl 代码 (实时更新, §6.7); 布局与键位比例自动适配终端 (§3.1)。
- **覆盖面板**: 行列菜单 (§6.3)、预设键值矩阵 (§6.5)、名称输入框 (§6.6)
  以覆盖层弹出, 关闭后回到网格区。
- **问题面板**: 仅在生效失败或存在警告时出现。
- **状态栏**: 只有操作集内键的提示 — 整个应用的操作面就这些键。

### 3.1 自适应布局 (布局↔键位↔终端)

三级自适应, 全程无手动布局操作:

1. **终端尺寸** (resize 事件) → 键盘区 = 终端宽高减去模式条/覆盖面板/问题面板/
   状态栏的余量。
2. **行高** = 键盘区高 ÷ 行数, 夹在 `[minKeyH, maxKeyH]` 之间; 行数超出时压缩到下限,
   多余行进入滚动 (方向键移动可及)。
3. **键宽按内容等比** (同 Termux 真键盘行为): 每行内, 各键宽 ∝ 该键 tekl 代码的
   显示宽度, 按比例拉伸填满整行宽; 最小宽度下限保证可点。

键宽/行高变化后, 焦点位置按 (行, 列) 索引保持, 不随比例跳变。

## 4. 数据模型 (对应 tekl.ebnf)

### 4.1 原则: 编辑模型 = 语法树

**不引入扁平化 JSON 模型**。TUI 的唯一事实源就是 `lib/tekl/parser.mjs` 产出的 AST,
它与 `tekl.ebnf` 的产生式一一对应, 无重映射、无信息丢失:

```
tekl.ebnf                  AST (parser.mjs)                  TUI 视图
────────────────────────────────────────────────────────────────────────────
N 命名键      →  {type:"key", key, kind:"named"}        →  单元格
S 修饰键      →  {type:"key", key, kind:"special"}      →  单元格 (CTRL 高亮)
"lit" 引号    →  {type:"key", key, kind:"literal"}      →  单元格 (引号字面)
A(A) 组合     →  {type:"combo", node:A, inner:A}        →  A(inner) 文本
A:N 标签      →  {type:"label", node:A, label}          →  node:label 文本
A.A 弹出      →  {type:"popup", main:A, popupNode:A}    →  main.popup 文本
M M 条目序列   →  row: Entry[]                            →  一行网格
M';\n' 行      →  rows: Row[]                             →  网格行
```

节点形状与 parser 的 `parseAtom`/`parseEntry` 完全一致:

- `key` `{key, kind}` — kind∈named/special/literal, 保留引号与大小写信息
- `combo` `{node, inner}` — 对应 `A(A)`, 递归嵌套
- `label` `{node, label}` — 对应 `A:N`, 包裹任意 A
- `popup` `{main, popupNode}` — 对应 `A.A`, **仅条目层** (M 层), 不出现在 atom 内

### 4.2 语法驱动: 序列化 (新增 lib/tekl/printer.mjs)

AST → tekl 源码是唯一需要新写的"反向"模块。按产生式逐节点打印, 语法无歧义 ⇒ 打印确定:

| AST 节点 | 打印 |
| --- | --- |
| key (named/special) | `key` (原样大小写) |
| key (literal) | `"text"` (引号回补, 保留 kind) |
| combo | `node(inner)` (递归) |
| label | `node:label` |
| popup | `main.popupNode` |
| row | 条目以空格连接, 行末 `;` |

**round-trip 保证**: 任意 AST → printer → parser 重解析, 结果与源 AST 逐节点相等;
测试逐条覆盖 `tekl.ebnf` 每条产生式。注释/空行/手写换行不保留 (tokenizer 本就丢弃 `#`)。

### 4.3 编辑操作 = 产生式变换 (由操作集触发)

所有编辑都是对 AST 的**结构化变换**, 合法性由语法定义。触发方式见 §6 —
矩阵累积选值、名称输入框、行列菜单、交换键:

| 操作 | 触发 | 变换 |
| --- | --- | --- |
| 新增按键 | M0 行列菜单: 列前/列后新增列 | `row.splice(i±1, 0, A)`, 默认 SPACE 键值 |
| 新增键盘行 | M0 行列菜单: 行前/行后新增行 | `rows.splice(r±1, 0, [A])` |
| 删除整键 | M0 行列菜单: 删除当前列 | `row.splice(i)`; 行空则 `rows.splice(r)` |
| 删除整行 | M0 行列菜单: 删除当前行 | `rows.splice(r)` |
| 交换两键 | M0: 选中键 → 移到他键 → SPACE | `[rowA[i], rowB[j]] = [rowB[j], rowA[i]]` |
| 改键值 | M1/M2 矩阵: CTRL 选值 (1 次) | 替换 `key.key` / `key.kind` (N/S/字面量) |
| 换成组合键 | M1 矩阵: CTRL 累积 ≥2 值 | wrap: 多值 → `combo` 链 (A(A)), 宏序 = 选择序 |
| 加/改/删标签 | M1/M2 名称框: 输入/清空 + ENTER | wrap/unwrap: `A → label{node:A, label}` (A:N) |
| 加/删弹出 | M2 矩阵: 选值 (创建) / 矩阵再选 | wrap/unwrap: `A → popup{main:A, popupNode:key}` (A.A) |

语法层唯一强制约束: popup 不能出现在 combo 的 inner (parser 的 nested popup 检查),
combo 内也不出现 label 之外的节点 (compiler 层会拒, 见 §7)。

### 4.4 生效点与无撤销

- 编辑以**生效点**为单元, 共四个: 矩阵 `ESC` (选值/组合完成)、名称框 `ENTER`、
  交换键 `SPACE`、行列菜单执行 — 每个生效点 = AST 变换 + 立即写盘 (§7)。
- 矩阵选值/名称输入过程是**未生效预览**, 键位反色/下划线显示, 真键盘不动;
  矩阵 `ESC` 与名称框 `ESC` 取消则不产生任何副作用。
- **无撤销**: CTRL 已承担选中/选值/菜单职责, 操作集内无撤销键; 逆操作替代
  (交换可再交换回去, 误改可重新选值) — 见 §9。
- 因每个生效点即写盘, 不存在"脏文件"状态, M0 `ESC` 可随时直接退出。

### 4.5 产生式集合 → 操作映射 (tekl.ebnf × TUI)

TUI 的每个操作都对应一条语法产生式 — 操作 = 产生式的"构造"或"消除":

| 产生式 | 含义 | TUI 构造操作 | 触发 | AST 变换 |
| --- | --- | --- | --- | --- |
| `N ::= "ESC" \| "TAB" \| … \| "SPACE"` | 命名键 | 选预设键值 | M1/M2 矩阵: 方向键移高亮 → CTRL | `key{key, kind:"named"}` |
| `N ::= '"'…'"' \| "'"…"'"` | 引号字面量 | 选字面量池 | 矩阵字面量区 → CTRL | `key{key, kind:"literal"}` |
| `S ::= "CTRL" \| "ALT" \| "FN" \| "SHIFT"` | 修饰键 | 选修饰键 | 矩阵修饰区 → CTRL | `key{key, kind:"special"}` |
| `A ::= N` | 单键原子 | 矩阵选 1 个命名键/字面量 | M1 SPACE → 矩阵 → CTRL ×1 | 主键值 = 单键 |
| `A ::= S` | 修饰单键 | 矩阵选 1 个修饰键 | 同上 | 主键值 = 修饰键 |
| `A ::= A(A)` | 组合键 | **累积选值** | M1 矩阵: CTRL 选 → 移动 → CTRL 选…(以此类推, ≥2 值) | `combo` 链, 宏序 = 选择序 |
| `A ::= A:N` | 标签 | 输入名字 | M1 ENTER → 名称框 → 输入 → ENTER | `label{node, label}` |
| `M ::= A` | 裸原子条目 | 矩阵单值 / 消去标签弹出 | 矩阵选 1 值; 名称框清空; 弹出置空 | 单元格 = 原子 |
| `M ::= A.A` | 弹出键 | 选弹出值 + 可选弹出名 | M2 SPACE → 矩阵 → CTRL; M2 ENTER → 名称框 | `popup{main, popupNode}` |
| `M ::= M M` | 行内条目序列 | 加列/交换 | M0 行列菜单 列前/列后新增列; 选中→移→SPACE 交换 | `row.splice` / 交换 |
| `M ::= M'\n'` | 代码换行 | — (无操作) | printer 规范化 | — |
| `M ::= M';\n'` | 键盘行 | 加行/删行 | M0 行列菜单 行前/行后新增行 / 删除当前行 | `rows.splice` |

**消除操作 (逆变换)** — 无撤销键, 全部以"重做产生式"代替:

| 消除目标 | 操作 | 触发 |
| --- | --- | --- |
| 删除标签 (`A:N`→`A`) | 名称框**清空**确认 | M1/M2 ENTER → 名称框 → 删空 → ENTER |
| 删除弹出键 (`A.A`→`A`) | 弹出矩阵**取消已选**到空 → ESC (空序列 = 移除弹出) | M2 SPACE → 矩阵 → CTRL(已选格) → ESC |
| 组合退化 (`A(A)`→`A`) | 矩阵重新选**单值**替换 | M1 SPACE → 矩阵 → CTRL ×1 → ESC |
| 删除整键 | 行列菜单 删除当前列 | M0 选中 → CTRL → 菜单 → 删除当前列 |
| 删除整行 | 行列菜单 删除当前行 | 同上 |
| 交换还原 | 再交换一次 | M0 SPACE 选中 → 移回 → SPACE |

**映射规则** (实现时 doc.mjs/mode.mjs 必须逐条可测):

1. 每条产生式至少有一个构造操作与一个消除操作 (除 `M'\n'` 语义无操作)。
2. 矩阵累积选值: 1 值 = `A::=N|S`; ≥2 值 = `A::=A(A)` 嵌套链 (深度≤3)。
3. 空序列语义: M1 矩阵空序列 ESC = 保持原值 (主键值不可为空);
   M2 矩阵空序列 ESC = 移除弹出键 (原本有弹出) 或取消 (原本没有)。
4. 弹出键名 (`M::=A.A` 中 popupNode 为 `A:N`) 经 M2 名称框构造, 与主键名同规则。
5. 字面量仅来自矩阵字面量池 (预设); 自定义字面量文本属开放问题 (§9)。

## 6. 交互设计 (操作集与模式)

### 6.1 操作集合与模式

操作集合 = 方向键 + `ALT` + `SPACE` + `CTRL` + `ESC` + `ENTER`。唯一的例外是
名称输入框 (任意文本输入, §6.6)。

模式 (ALT 线性循环):

```
M0 键盘编辑 ──ALT──▶ M1 主键编辑 ──ALT──▶ M2 弹出键编辑 ──ALT──▶ M0 ──▶ …
```

| 键 | M0 键盘编辑 | M1/M2 (编辑) | 预设值矩阵 | 行列菜单 | 名称输入框 |
| --- | --- | --- | --- | --- | --- |
| `←→↑↓` | 移动光标 | — | 移动高亮 | 选择菜单项 | 文本光标 |
| `SPACE` | 选中/交换 (§6.2) | 弹出预设值矩阵 | — | 执行菜单项 | — |
| `CTRL` | (选中后) 行列菜单 | — | 选值 (可累积) | — | — |
| `ESC` | 退出程序 | M1→M0, M2→M1 (逐级) | 更新 Termux + 回 M1/M2 | 关闭菜单 | 取消 |
| `ALT` | → M1 | → M2 / → M0 | — | — | — |
| `ENTER` | — | 名称输入框 | — | — | 确认 (更新 Termux) |

### 6.2 M0 键盘编辑

- `←→↑↓` 移动光标; 光标所在键高亮。
- `SPACE` 选中 (标记) 当前键位; **再次 SPACE**:
  - 光标已移到另一键位 → **交换两个键** (写盘+reload);
  - 仍在同一键 → 取消选中。
- 选中后 `CTRL` → 弹出**矩阵行列操作菜单** (§6.3)。
- `ESC` → 退出程序 (所有已生效变更均已写盘)。

### 6.3 矩阵行列操作菜单

作用于光标所在键 (行 = 当前行, 列 = 当前列):

```
┌ 行列操作 ───────────────────┐
│ ▸ 行前新增行                 │
│   行后新增行                 │
│   删除当前行                 │
│   列前新增列                 │
│   列后新增列                 │
│   删除当前列                 │
└─────────────────────────────┘
↑↓ 选择 · SPACE 执行 · ESC 关闭
```

| 菜单项 | 效果 (写盘+reload) |
| --- | --- |
| 行前/行后新增行 | 当前行上/下方插入新行 (含 1 个默认键) |
| 删除当前行 | 整行移除 |
| 列前/列后新增列 | 当前键左/右侧插入新键 (默认 SPACE 键值) |
| 删除当前列 | 移除当前键 |

执行后自动关闭菜单, 写盘并推送 Termux。删除当前行后光标落到相邻行。

### 6.4 M1 主键编辑 / M2 弹出键编辑

编辑对象 = M0 中选中的键 (未选中则为光标所在键)。两个模式逻辑完全一致,
唯一区别是 `ENTER` 打开的输入框:

| 操作 | M1 主键编辑 | M2 弹出键编辑 |
| --- | --- | --- |
| `SPACE` | 弹出预设键值矩阵 (编辑主键值/组合) | 弹出预设键值矩阵 (编辑弹出键值) |
| `ENTER` | 弹出**主键名输入框** | 弹出**弹出键名输入框** |
| `ESC` | 返回 M0 | 返回 M1 |

M2 中无弹出键时: 矩阵选值确认即创建弹出键; 名称输入框仅在弹出键存在时可用
(否则提示"先选择弹出键值")。

### 6.5 预设键值矩阵

`SPACE` 弹出覆盖面板, 展示全部预设键值:

```
┌ 预设键值 ────────────────────────────┐
│  CTRL   ALT   FN   SHIFT   (修饰键)   │
│  ESC    TAB   ENTER  BKSP  DEL  INS   │
│  HOME   END   PGUP  PGDN  UP   DOWN   │
│  LEFT   RIGHT SPACE  SCROLL DRAWER    │
│  KEYBOARD  BACKSLASH  QUOTE  APOSTROPHE │
│  F1  F2  F3  F4  F5  F6               │
│  F7  F8  F9  F10  F11  F12            │
│  "~"  "|"  "\"  "%"  "$"  "#"  "@"  "^" (字面量池) │
└──────────────────────────────────────┘
←→↑↓ 移动高亮 · CTRL 选值(可累积) · ESC 完成并更新 Termux
```

- `←→↑↓` 在矩阵中移动高亮。
- `CTRL` 选中当前格的值 —— **可连续移动并多次 `CTRL` 累积选值** (以此类推),
  累积的顺序即组合宏的顺序: 如 `CTRL`(移到 C 格)`CTRL` = `CTRL(C)`; 三个 =
  `CTRL(ALT(X))` 的宏 `CTRL ALT X`。再次 `CTRL` 同一格 = 取消该项。
- 打开时已存在的值: 其组成项在矩阵中预高亮; 累积选择**替换**原值。
- 已选序列清空时的 `ESC` (空序列语义, §4.5 规则 3): M1 = **保持原值** (主键值
  不可为空); M2 = **移除弹出键** (原本有弹出) 或取消 (原本没有)。
- **`ESC` = 完成**: 更新 Termux 实际方案 (校验 → 写盘 → reload) 并回退到 M1/M2。
- 选中过程中, 目标键位上的 tekl 代码实时预览 (反色/下划线), 所见即所得 (§6.7)。

### 6.6 名称输入框 (唯一文本输入)

`ENTER` 弹出, 覆盖面板:

```
┌ 主键名 ──────────────────┐
│ [COPY_____________]       │
└──────────────────────────┘
输入任意文本 · ENTER 确认 · ESC 取消
```

- 任意文本输入 (唯一允许自由输入的地方, 复用 opentui Input 组件)。
- `ENTER` = 确认 → 校验 → 写盘 + reload → 回 M1/M2; **清空确认 = 移除名字**。
- `ESC` = 取消, 不改动, 回 M1/M2。

### 6.7 所见即所得规则 (最高要求)

1. **单元格 = Termux 实际按键的样子, 内容 = 该键的实际 tekl 代码**: 每个键位以
   Termux 键帽外观渲染, 内容是该键的 tekl 源码片段 (`ESC` / `CTRL(C)` /
   `HOME:Start` / `ESC.F1` / `"~"`), 由 printer 对单条目逐节点生成 ——
   **界面看到的 = 写进文件里的 = 真键盘上的**, 三者同源同一渲染管线。
2. **tekl 代码实时更新**: 矩阵选值累积、名称框逐字输入时, 键位内的 tekl 文本
   **即时重渲染** (未生效态反色/下划线); 生效后实化。
3. **实体操作即推送 Termux**: 四个生效点 — 矩阵 `ESC`、名称框 `ENTER`、交换键
   `SPACE`、行列菜单执行 — 一律立即执行 `校验 → 原子写盘 → termux-reload-settings`,
   真键盘实时更新; 没有手动保存、没有批量应用。
4. **布局/键位自动适配**: 键帽尺寸随终端 resize 实时重排 (§3.1), 键宽按 tekl 文本
   宽度等比拉伸填满行宽 — 与 Termux 真键盘的拉伸行为一致。
5. **失败即回滚**: 生效点校验失败则不写盘, 预览回滚, 问题面板显示错误 (§7);
   真键盘保持上一有效状态。
6. **行宽如实呈现**: 各行键数/文本宽不一致照实显示, 不强行对齐。

### 6.8 操作状态机架构 (用户侧)

#### 6.8.1 一张图看懂

```
┌───────────────────────────────────────────────────────────┐
│                    M0 键盘编辑 (看整个键盘)                  │
│     ←→↑↓ 移动光标                                          │
│     SPACE 选中(标记) → 移到他键 → SPACE 交换键              │
│     选中后 CTRL → 行列操作菜单                              │
│     ESC 退出                                               │
└─────┬───────────────┬──────────────────┬──────────────────┘
      │ ALT           │ SPACE 选中        │ (选中后) CTRL
      ▼               ▼                  ▼
┌────────────┐  ┌────────────────┐  ┌──────────────────┐
│ M1 主键编辑 │  │ (标记选中态)     │  │ 行列操作菜单       │
│ M2 弹出键编辑│  │  ① SPACE 值矩阵 │  │ 行前新增行…        │
└────┬───────┘  │  ② ENTER 名输入框│  │ 删除当前列         │
     │          └────────────────┘  └──────────────────┘
     │ SPACE            │ ENTER         SPACE 执行(写盘)
     ▼                  ▼
┌────────────┐  ┌────────────┐
│ 预设键值矩阵 │  │ 名称输入框   │
│ ←→↑↓ 移动   │  │ 任意文本     │
│ CTRL 选值   │  │ ENTER 确认  │
│ (可累积)    │  │ ESC 取消    │
└────┬───────┘  └────────────┘
     │ ESC = 完成
     ▼
 Termux 已更新 (写盘+reload) ──▶ 回 M1/M2
```

**读图方式**: 用户活在 M0 (看键盘) 和 M1/M2 (改选中的键) 两个层面;
矩阵与输入框是瞬态操作面板, 完成后都回到模式层。SPACE = 选中/弹出矩阵;
ENTER = 名称; CTRL = 选值/菜单; ESC = 完成生效 / 返回 / 退出 (逐级: M2→M1→M0);
ALT = 换模式 (M0→M1→M2→M0)。

#### 6.8.2 三条铁律

1. **没有保存**: 四个生效点 (矩阵 ESC、名称框 ENTER、交换、菜单操作) 立即写盘并
   推送真键盘, 用户永远不需要等。
2. **定了才算数**: 矩阵选值、名称输入都是"未生效"状态 (反色预览), 生效前真键盘不动。
3. **界面 = 真键盘**: 任何时候你看到的键盘样子, 就是真键盘现在/即将的样子。

> 实现说明: 本用户状态机由 `model/mode.mjs` 承载, 内部状态 = (模式 M0/M1/M2,
> 选中标记, 面板: 无/菜单/矩阵/输入框, 矩阵高亮, 已选值序列)。对外只暴露上图
> 两层状态与操作集。

### 6.9 操作流示例

- **加组合键 `CTRL(C)`**: M0 移到 `C` → SPACE 选中 → ALT (M1) → SPACE (矩阵) →
  ↑↓ 移到 `CTRL` → CTRL 选值 → 移到 `C` 格 → CTRL 选值 → ESC (更新 Termux, 回 M1) →
  ESC (回 M0)。键位实时显示 `CTRL(C)`。
- **加弹出 `ESC.F5`**: M0 选中 `ESC` → ALT → ALT (M2) → SPACE (矩阵) → 移到 `F5` →
  CTRL → ESC (弹出键创建, 更新 Termux, 回 M2)。
- **改显示名**: M1 → ENTER (名称框) → 输入 `Start` → ENTER (更新 Termux)。
- **交换两键**: M0 SPACE 选中 `A` → 移到 `B` → SPACE (交换, 更新 Termux)。
- **删除当前行**: M0 SPACE 选中该行某键 → CTRL (菜单) → ↓ 移到"删除当前行" →
  SPACE (执行, 更新 Termux)。

编辑约束 (语法层由 parser 保证, 语义层由 Phase 1 校验保证):
语法层: popup 不出现在 combo inner 内。语义层 (compiler 规则, doc.mjs 预检查并在
问题面板提示): 修饰键行内不可重复; `key`/`macro` 互斥(编译成 JSON 时); popup 仅一层
效果; rename/popup 不可放入 `()`; 标签非空。

### 6.10 操作逻辑规范 (ttoll 行为核心语言)

操作分发逻辑不直接写 if/else, 而是用一门 **CFG 基底的小 DSL** 声明式描述
(文法见 `docs/ttoll.ebnf`) 作为 `mode.mjs` 的权威规格 — **行为全部声明化**,
数据驱动, 可静态检查。程序 = **规则段** (声明"谁触发谁") + **行为段** (声明
"动作做什么"), 运行时由通用解释器按程序执行, 不存在硬编码的 JS 状态机。

**语言形状** (无空格 DSL, 键值直接使用, 每条规则以换行结束):

```ebnf
C = M , '.' , P , '.' , ( K | D ) , [ '?' , G ]* , '>' , id , "\n"   (* 操作规则 *)
AC = '@' , id , "\n" , { S , "\n" }                                  (* 动作定义 *)
S = 'mode' , N | 'escpanel' | 'sel' | 'unsel'
  | 'apply' | 'cancel' | 'exit' | 'seterrors' , str | prim          (* 语句 *)
```

- 规则 = 模式 `M` + `.` + 面板 `P` + `.` + 单键, 可带**链式守卫** `?G?G…`
  (均须命中), `>` + 动作 id, 换行结束。
- 动作定义 = `@id` 换行后跟**语句行**; 语句 = 内置操作 (`mode 1` 跳模式,
  `escpanel` 关面板, `sel`/`unsel` 选中, `apply`/`cancel`/`exit` 效果,
  `seterrors 文案` 报错) 或**原语** (`prims.mjs`: `move`/`swap`/`menu.*`/
  `matrix.*`/`name.*`, 可经 `registerPrim` 扩展)。
- 同一 (M, P, 键) 允许多条规则, 运行时按声明序求守卫, 首条命中执行。

**动作 id 表** (用途直写, 中文/数字均可):

| id | 用途 |
| --- | --- |
| 移动焦点 | 网格光标 / 矩阵高亮 / 菜单焦点 移动 (歧义按当前面板) |
| 选中焦点键位 | 设置选中标记 |
| 交换焦点键位并实时更新 | 交换两键 + 写盘 reload + 清选中 |
| 打开预设键值矩阵 | 打开预设键值矩阵 |
| 弹出焦点键位行列操作矩阵菜单 | 行列操作菜单 (增删行/列) |
| 编辑主键名称 / 编辑弹出键名称 | 名称输入框 |
| 完成矩阵编辑 | 矩阵生效: 按模式 M1=主键值 / M2=弹出键值 (含空序列语义) |
| 应用 / 丢弃 | 名称框确认 / 取消 |
| 0 / 1 / 2 | ALT: 模式跳转 (目标模式 = 数字本身) |
| 退出程序 | ESC(模式0): 退出程序 |

**完整规则程序与行为段** — 基座 `tekl.ttoll` 即为规范实现 (规则段 + `@` 行为段),
`0.-.SPACE?nosel>选中焦点键位` 触发动作, 其行为段 `@选中焦点键位\n  sel` 声明
"做什么"; 运行时解释器 (`mode.mjs`) 按程序执行, 无硬编码 JS 状态机。

**完整程序** (规则 + 行为段) — 规范实现见仓库根 `tekl.ttoll`, 覆盖:

- **M0 键盘编辑**: `0.-.UP>移动焦点`, `0.-.SPACE?nosel>选中焦点键位`,
  `0.-.SPACE?same>取消选中焦点键位`, `0.-.SPACE?diff>交换焦点键位并实时更新`,
  `0.-.CTRL?sel>弹出焦点键位行列操作矩阵菜单`, `0.-.ALT>1`, `0.-.ESC>退出程序`
- **行列菜单** (面板 R): `0.R.UP>移动上`, `0.R.DOWN>移动下`,
  `0.R.SPACE>执行`, `0.R.ESC>关闭面板`
- **M1/M2 编辑**: `1.-.SPACE>打开预设键值矩阵`, `1.-.ENTER>编辑主键名称`,
  `1.-.ALT>2`, `1.-.ESC>返回键盘模式` (M2 对称, `2.-.ALT>0`/`2.-.ESC>返回主键模式`)
- **矩阵** (面板 M): `1.M.UP>移动焦点` 等, `1.M.CTRL?noinsel>选中列表示选值`,
  `1.M.CTRL?insel>取消选值`, `1.M.ESC>完成矩阵编辑` (M2 同构)
- **名称框** (面板 N): `1.N.ENTER>应用`, `1.N.ESC>丢弃`
- **行为段**: `@移动焦点\n  move`, `@交换焦点键位并实时更新\n  swap`,
  `@完成矩阵编辑\n  matrix.finish`, `@1\n  mode 1`, … — 每个规则动作都有
  `@` 定义 (内置操作 + 原语), 空序列语义 (M2 移除弹出 / M1 保持原值) 内建于
  `matrix.finish` 原语。

**静态检查** (校验 ttoll 程序时, 计入 `npm test`):
1. **键/守卫合法性**: 规则中只出现 `K/D` 键值与已知守卫名。
2. **原语合法性**: 行为段语句只允许内置操作或已注册原语名 (含插件 `registerPrim`)。
3. **动作完整性**: 每条规则引用的动作必须有 `@` 行为段定义 (或已注册 JS 动作覆盖)。
4. **歧义标注**: 同 (M, P, 键) 多规则属刻意上下文分派, 以注释标注各规则上下文
   前件; 运行时按声明序首条命中, 行为与文档一一对应。
5. **可达性**: 从模式 `0` 出发, 所有目标模式可达 (BFS)。
6. **生成**: 规则表摊平为 `Map<M|P|键, Rules[]>` 数据驱动 `mode.mjs` 分发,
   零 if/else; 动作脚本编译为闭包 (内置操作直接执行, 原语查表调用)。

## 7. 校验与错误展示

- **生效点校验**: 每个生效点 (矩阵 `ESC`、名称框 `ENTER`、交换键 `SPACE`、
  行列菜单执行) 触发 `printer(AST) → parse → compile` → `validateTermuxJson` +
  `validateExtraKeyJson` (复用 `compiler-io.compileSource` 链路)。
  失败 → 不写盘, 界面预览回滚, 问题面板红色定位 (复用 `formatParseError` 行列+caret
  语义, 投影到网格坐标)。
- **常驻警告**: 行宽不一致 / 缺 DRAWER / 缺 KEYBOARD / 空字段 → 问题面板黄色,
  不阻塞生效。
- 写盘走 `updateProperties` (原子 `.tekl.bak` + 读回校验 + round-trip), 与 Phase 1
  完全一致; 写盘成功后自动 `reloadSettings()`。

## 9. 风险与开放问题

1. **opentui fork 差异**: 本仓库用 `@xincil/opentui-*@0.4.7` (lock 指向 npmmirror),
   与上游 `@opentui/*` 文档可能 API 漂移。**M1 第一件事**是验证 keypress 事件能否
   区分 `ESC`/`ALT`/`SPACE`/`ENTER`/方向键 (Termux 硬件键盘的 ALT 与 ESC 事件语义),
   以及 Input 组件文本输入, 不行则回退 `opentui-core` 的 Renderable 直达 API。
2. **无撤销**: CTRL 已承担选中/选值/菜单职责, 操作集内没有撤销键; 依赖逆操作
   (交换可再交换、误改可重新选值)。若实测难以忍受, 需为撤销重新分配键位 —
   **待决策**。
3. **矩阵组合上限**: 累积选值无显式上限, 需限制组合深度 (≤3 层) 并在矩阵面板
   提示, 防止生成超长宏。
4. **零构建 vs JSX**: Node 26 不原生支持 JSX; 方案用 `createElement` 少写 JSX 保持无构建。
   若团队更想要 JSX, 需引入 babel/tsx 构建, 改变"纯 ESM 无构建"仓库约定 — 需决策。
5. **Termux 真实渲染**: CJK 宽度、256 色、FFI (需 `--experimental-ffi`), 确认正式入口
   同样携带启动旗标。
6. **自动 reload 频率**: 每次生效都自动 `termux-reload-settings`, 连续编辑会频繁
   重载真键盘 (可能闪烁); 若实测干扰, 需引入节流或手动触发 — M3 验证后定稿。
7. **规范化丢注释**: 接受并文档化; 若用户强烈依赖注释, M5 引入 token 级无损回写。
